# Casos de uso

Estudos de caso reais que combinam prompts, skills e/ou MCPs para resolver problemas concretos.

Cada caso vive em sua própria pasta com:

- `README.md` ou `case.md` usando `CASE-TEMPLATE.md`.
- Diagramas em `assets/diagrams/`.
- Links para os artefatos usados em `build/`.
