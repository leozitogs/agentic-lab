# Trilha avançada

Depois da trilha de fundamentos (`learn/roadmap/`), a trilha avançada aprofunda a construção de sistemas com IA em **11 módulos**.

## Como funciona

- **Ritmo livre.** Cada módulo leva de uma a duas semanas, conforme o time.
- **Ordem sugerida, não obrigatória.** Os módulos 1 a 4 formam a base; 5 a 10 podem ser feitos em qualquer ordem; o 11 fecha a trilha.
- **Comparar antes de adotar.** Todo módulo pede para comparar pelo menos duas ferramentas no mesmo exercício.
- **Dados públicos ou sintéticos.** Nenhum exercício usa dado real de pessoas ou de sistemas internos.
- **Sem entregável, o módulo não fecha.** Vale a regra das seis perguntas do README.
